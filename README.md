# 🎙️ AI Voice Assistant

An intelligent AI-powered voice assistant built with Python.

## Features
- 🎤 Speech recognition (voice to text)
- 🧠 Natural language processing
- 🔊 Text-to-speech responses
- 🌐 Web search integration
- 📅 Task & reminder management

## Project Structure
```
AI-VOICE-ASSISTANT/
├── src/
│   ├── assistant/      # Core assistant logic
│   ├── speech/         # Speech recognition & TTS
│   ├── nlp/            # Natural language processing
│   └── utils/          # Helper utilities
├── assets/
│   └── audio/          # Audio files
├── tests/              # Unit tests
├── docs/               # Documentation
├── requirements.txt    # Python dependencies
└── main.py             # Entry point
```

## Setup

### Prerequisites
- Python 3.9+
- Microphone

### Installation
```bash
git clone https://github.com/paavana-410/AI-VOICE-ASSISTANT.git
cd AI-VOICE-ASSISTANT
pip install -r requirements.txt
```

### Run
```bash
python main.py
```

## Usage
Speak clearly into your microphone after launching. The assistant will listen, process your command, and respond.
